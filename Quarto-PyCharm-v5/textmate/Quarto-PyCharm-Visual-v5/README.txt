QUARTO PYCHARM VISUAL v5

This is the TextMate part. It keeps the visual syntax work from v4 and gives ## slide
headings a dedicated semantic scope. The companion JetBrains plugin in this package
overlays the entire ## slide title in strong pastel red and adds folding.

Install:
Settings -> Editor -> TextMate Bundles -> +
Select this Quarto-PyCharm-Visual-v5 folder (the one containing package.json).
Disable older custom Quarto bundles so only one owns .qmd.
